# References

The checked reference list for Chapters 1 and 2. It replaces the proposal's list, which
could not be reused (see *Not carried over from the proposal*, below).

**How citations are written.** Chapters cite by key, in square brackets:
`[Rahman2023]`. The keys are stable; converting them to the numbered IEEE style the
department's template uses is a mechanical step for when the dissertation is assembled,
and doing it earlier would mean renumbering every time a source is added.

**What "checked" means here, exactly.** On 8 October 2026 each source below was looked
up and its existence, authors, title, venue and year were confirmed. How far the
*content* was checked differs, and the last column says which:

- **A — primary text read.** The page or document itself was opened and the statement
  made about it in the chapters was read there.
- **B — abstract read.** The abstract was read on the publisher's, arXiv's or an
  institutional repository's own page.
- **C — record confirmed.** The bibliographic record and a summary of the abstract were
  confirmed from search results that pointed at the publisher's or authors' pages. The
  page itself was not opened.

**No paper's full text was read for this list.** Every statement the chapters make
about a paper is one its abstract supports. Before submission the author must open and
read each work cited, the level C entries first, and confirm that the sentence citing
it says what the work says.

## Could not be checked, and so not cited

Two documents the proposal relied on could not be opened from the machine this was
written on, and no statement in Chapters 1 or 2 rests on either.

- **NSA, "Mitigating Cloud Vulnerabilities," January 2020.** Secondary pages confirm
  that it exists and that it names four classes of cloud vulnerability. The document
  itself returns an access error. It is also an NSA publication, not a joint NSA and
  CISA one as the proposal describes it. The point it was cited for, that
  misconfiguration is a leading cloud risk, now rests on [CSA2024].
- **NSA and CISA, "Kubernetes Hardening Guidance."** The same access error. Eleven of
  the rubric's citation claims rest on it and remain unverified (Section 3.8). If a
  copy is obtained, both this entry and those claims can be settled together.
